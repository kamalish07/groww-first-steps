# Groww First Steps

An independent Groww-inspired educational prototype for a product case study.

The app offers beginner and experienced onboarding, an optional guided Stocks learning track, four sequential lessons, course completion unlocking simulated investing, and optional virtual practice with three scenarios. Classic mode remains available, and preferences can be changed in Settings.

All prices, company figures and scenarios are illustrative. No real transactions or investment recommendations are provided. Course completion does not establish investing readiness. The explainer is scripted, and progress is stored in the current browser.

This repository contains the static website files used by GitHub Pages. It is not affiliated with or endorsed by Groww.
